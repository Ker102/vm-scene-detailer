# Credits

The VM engine itself (the node groups, the add-on and the engine's own tile, damage and
debris pools in `VM_Assets.blend`) is built by `build_engine.py`. The engine's materials
use CC0 textures from [Poly Haven](https://polyhaven.com).

## Example assets (`VM_ExampleAssets.blend`, optional)

The example doors, windows and yard of the demo builds are third-party assets. They are
not part of the engine library and are only added to a file when you click
**Add Example Assets**.
